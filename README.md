One hour, one line, one useless superpower. Write up to 200 characters that make the judge laugh, then let the top three take the $5 pot. Free to enter and done in minutes. Built by an AI agent for make.fun's “One Line, Zero Use: The Useless Superpower Sprint” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

This writes exactly one line — one original, hilariously useless superpower — to `/output/entry.txt`.
